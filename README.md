# Daily Flow Planner

An internal workspace: a Kanban board for company projects, quotations &
agreements with PDF output, money/reminder tracking, and a personal daily
planner — built on TanStack Start + Supabase.

## Stack

- **TanStack Start** (React 19, file-based routing, SSR + server functions)
- **Vite 8** + **Tailwind CSS v4** + **shadcn/ui** (Radix)
- **Supabase** — Postgres, Auth, Row Level Security
- **Drizzle Kit** — SQL migrations (`drizzle/migrations`)
- **Vercel** — hosting (nitro `vercel` build target)

## Local development

Requires Node.js 20+.

```sh
npm install
cp .env.example .env   # then fill in your Supabase values
npm run dev
```

The app runs at the URL Vite prints (default http://localhost:8080).

## Environment

See [.env.example](.env.example) for the full list. Values come from your
Supabase project (dashboard → Project Settings → API / Database). Locally they
live in `.env`; in production set them in the Vercel project settings.

## Database migrations

SQL migrations live in `drizzle/migrations` and are applied against the database
in `DATABASE_URL`:

```sh
npx drizzle-kit migrate
```

The schema covers profiles, members, projects/stages/tasks, quotes, agreements,
payment milestones, and reminders, all with RLS enabled. Reminder rows are
generated by the `public.generate_reminders()` SQL function; schedule it with
`pg_cron` in Supabase (it is not scheduled by the migrations).

## Deployment (Vercel)

The build uses the nitro `vercel` preset. Connect this repo to Vercel, set the
environment variables above, and deploys run on every push to the main branch.
